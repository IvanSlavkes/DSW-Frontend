## Criterios del TP

La interfaz usa React y TypeScript, representa modelos con tipos y consume una API mediante Axios. Se usa Tailwind CSS y estilos responsive en las pantallas existentes. El detalle con consulta al backend y el flujo de unión a equipos están acordados, pero siguen pendientes.

La documentación técnica no reemplaza las minutas ni el tracking de tareas del grupo. La propuesta funcional compartida está desactualizada y debe actualizarse con el alcance vigente.
